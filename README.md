Run python simulator.py to get started.

Once it is running, a menu will pop up asking which algorithm you want to test. If you pick a CPU scheduling method like First-Come, First-Served or Round Robin, you just need to tell the program how many processes there are, when they arrive, and how much time they need. Just type the numbers with spaces in between. For Round Robin, it will also ask for your time limit per task. The program then handles the math, drawing a Gantt chart timeline and calculating your average wait times.

If you choose the Banker's Algorithm to test for deadlocks, the program walks you through entering the resources your processes currently hold versus what they ultimately need. Type in the numbers row by row when prompted. It will crunch the data, show you the Need Matrix, and let you know if your system is in a safe state—complete with the exact step-by-step sequence to keep things from crashing.
